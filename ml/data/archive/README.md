# Archived datasets

These files are **not** part of the active evaluation pipeline.

## `rf_ground_truth_labels.csv`

Copied from an older Random Forest experiment (`RF_BlindTesting/ground_truth_labels.csv` in the linear-regression prototype). It has 136 rows, including 42 filenames with no matching image in `demo/segmented_wells/`, and disagrees with `../ground_truth_labels.csv` on most overlapping wells.

Kept for historical reference only. Do not use it to train or score the current models.
